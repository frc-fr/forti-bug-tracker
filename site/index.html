Les versions et le statut FortiOS sont déduits des listes de modèles supportés des Release Notes. Ce ne sont pas les dates End of Life ou End of Sale, que Fortinet ne publie pas dans ces documents : consultez le portail Fortinet (compte requis).

Comment lire les statuts
Affecté
Le bug est listé dans les Known issues de cette version.
Corrigé
Le correctif est dans cette version ou une version antérieure de la même branche.
Potentiellement affecté
Le bug est corrigé ou déjà présent plus tard sur cette branche. Fortinet ne publie pas la version d'introduction : cette version peut ne pas être touchée.
Inconnu
Les notes ne permettent pas de conclure pour cette version, par exemple quand le bug n'est signalé comme nouveau que dans une version plus récente.

Une mention de matériel signifie que les notes le citent, pas que seul ce matériel est touché. La plupart des bugs n'en citent aucun : ils restent affichés comme génériques. Un ASIC (NP7, SoC4…) est indiqué à titre d'information, à vérifier pour votre modèle.
